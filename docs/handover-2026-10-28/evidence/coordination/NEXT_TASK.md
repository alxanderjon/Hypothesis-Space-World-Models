# Next research decision — preserve library-induction success; test representation expansion

Close the nine-monomial guide and active-probe variants as restricted search diagnostics. The unexecuted active-candidate-disagreement draft did not create scientific data. Do not tune its policies, pair terms, candidate budget or probe heuristics.

Preserve `growing_callable_program_library_v1` and its fresh confirmation as positive evidence for a narrow but real capability: observations selected a recurring subprogram, the system retained it as an executable primitive, and that primitive reduced later search cost on new compositions under matched controls. Keep the claim bounded to the supplied 2D language and controlled state banks.

The next materially different question is whether representation can expand when the recurring response is outside the current symbolic language. Investigate a hybrid acquisition rule that (1) rejects the current program class using acquisition-only held transitions, (2) learns a callable residual module from multiple acquisition systems without equations or family IDs, (3) admits it only on source-family transfer, and (4) allows later search to compose it with the frozen symbolic library. Compare against a fixed universal approximator, random callable, extra base search and the frozen library at matched data/compute.

Do not merely add more hand-selected operators or create another favorable exact-motif benchmark. Explicitly count persistent callable parameters/bytes, retained examples, per-system coefficients, search evaluations and observations. Use whole-mechanism folds for development and keep a new mechanism family untouched until the rejection/admission rule and all thresholds are frozen.
